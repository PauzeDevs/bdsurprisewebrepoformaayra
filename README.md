# Maayra's birthday photo diary

A small, mobile-first birthday website with a warm Pinterest / film-photo diary feel. Built with plain HTML, CSS and JavaScript for GitHub Pages.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Once the deployment finishes, the site should be available at:

https://pauzedevs.github.io/bdsurprisewebrepoformaayra/

## Music

The soundtrack button embeds Billie Eilish's official “BIRDS OF A FEATHER” YouTube video after the visitor taps it. Playback depends on YouTube availability and browser settings.
