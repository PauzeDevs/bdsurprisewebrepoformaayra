# Maayra's birthday photo diary

A small, mobile-first birthday website with a warm Pinterest / film-photo diary feel. Built with plain HTML, CSS and JavaScript for GitHub Pages.

## Add the five supplied photos

Create an `assets` folder in the repository and add the supplied photos with these exact filenames:

| Filename | Photo |
| --- | --- |
| `river.jpg` | River-side full-length photo (hero) |
| `palace.jpg` | White outfit at the palace |
| `selfie.jpg` | Green top selfie |
| `guitar.jpg` | Black-and-white guitar photo |
| `forest.jpg` | Forest photo from behind |

The site references these paths from `index.html`.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Once the deployment finishes, the site will be available at:

`https://pauzedevs.github.io/bdsurprisewebrepoformaayra/`

## Music

The soundtrack button starts the Billie Eilish “BIRDS OF A FEATHER” YouTube embed after the visitor taps it. Playback depends on YouTube availability and browser settings.
